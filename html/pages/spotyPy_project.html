Playlist update bot

SpotiBot

A Python bot that automates Spotify playlists using external song databases.

Task

This project started as a way to learn Python, driven by my passion for Spotify.

Functionality

The bot automatically edits playlists in Spotify. Starting from a seed, it collects many new and popular songs from different databases, which gives the best selection from a wide range of sources. It then calculates an index for each song, a formula weighting popularity and release date, which determines the song's rank in the final playlist.

Every Wednesday and Sunday at midnight, the bot sorts the songs by index, removes duplicates and unpopular tracks, truncates the list to 100 songs and adds them to Spotify. This works for any genre and isn't limited by the number of databases. Planned: more databases and a web interface.
