AR Process Documentation

My bachelor thesis: Augmented Reality tools to document processes in logistics.

Task

This project was my bachelor thesis from 2023. The main goal was to implement a software add-on that provides a documentation toolbox in the AR space of the Microsoft HoloLens. The add-on was then evaluated together with the Port of Kiel to analyse the prototype's functionality and possible use cases.

Functionality

The add-on has five core functions for a seamless documentation process: (1) draw, (2) erase, (3) text, (4) save/load and (5) settings. With them, users can document any business process, inside or outside a company.
