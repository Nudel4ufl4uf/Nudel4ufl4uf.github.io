Self-hosted home server

NudelHome

My own home server for all smart home devices, running locally on a Raspberry Pi.

Task

The idea was to run my own home server locally on a Raspberry Pi for all my smart home devices.

Functionality

The server gives all smart home devices a much faster connection. Because everything runs locally, no data passes through cloud data centers, which is a big win for privacy. Combined with my Mycroft project, I can control all devices by voice and fully replace Google services and other cloud providers for smart home.

The downside: the system can't be reached from outside the network without special setup, which limits automations that need external data. Since all core requirements are met, the better privacy and security matter more to me. Thanks to the open-source community, the possibilities keep growing.
